# Pivot 0.4.5

Pivot now runs standard MuJoCo passive viewers inside the workbench. Open a saved Python script, click **Run file**, and switch between your code, simulation, and telemetry while it runs.

## What’s new

- **Embedded Python simulation.** Existing scripts that call `mujoco.viewer.launch_passive()` and `viewer.sync()` can stream into Pivot. Debug shows automatic joint, actuator, and sensor signals. Stop ends the run and keeps captured frames available for replay. Try the [standalone pendulum example](../../examples/passive-viewer/pendulum.py).
- **MuJoCo 4.0.1 and MCAP 1.6.0.** The Windows Python setup downloads replacement packages before migrating a managed MuJoCo 3.x installation. The bundled pendulum replay was regenerated with 4.0.1.
- **Visual Editor (Prototype).** CodeMirror provides mouse-driven, single-file editing, basic Python completion, and **Ctrl+S → Run file**. Saves preserve consistent line endings and detect external edits. LazyVim remains the default, with indent guides that follow the active theme.
- **Smoother fullscreen controls.** Double-click or double-tap the simulation viewport to toggle fullscreen. The controls fade together after the idle timeout, and camera drags keep their usual behavior.
- **Configurable Pomodoro.** Set focus and break lengths, schedule long breaks, and enable an optional chime that repeats for about ten seconds. Pause and resume from the header or dialog, and reset from either a focus session or a break.

## Switch editors

Press **Ctrl+Shift+P**, search for **Editor profile**, then select **Visual Editor (Prototype)** or **Pivot · bundled LazyVim**.

> [!WARNING]
> The Visual Editor is for trying small edits. Use LazyVim for day-to-day work and language-server features.

## Install or upgrade on Windows

Download the Windows x64 MSI and its SHA-256 checksum from the release assets. For an upgrade, close Pivot before running the installer. If you already use live simulation or MCAP export, rerun the managed Python setup after installing. See the [Windows desktop guide](../DESKTOP.md#update-pivot).
